# Security Policy

## Reporting Security Issues

The Oxia maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/oxia-db/oxia/security/advisories/new) form.

For more details, see the [Oxia security policy](https://github.com/oxia-db/oxia/blob/main/SECURITY.md).
